## 기술 구조와 운영 시 유의점

- 단일 정적 HTML이다. 현재 상담 신청 폼, 자체 서버 API, ERP 전송 코드는 없다. 네이버 예약은 외부 페이지 이동이며 ERP에 예약 데이터를 자동으로 보내지 않는다.
- 스타일은 `https://cdn.tailwindcss.com`과 Pretendard 외부 폰트에 의존한다. 실제 서비스의 빌드 방식에 맞게 CSS를 준비하고, 배포 후 화면을 확인한다.
- HTML 하단의 `landing-local-editor-script`와 상단 `landing-local-editor-style`은 로컬 문구 편집 기능이다. 스크립트 첫 부분에서 `file:` 프로토콜이 아니면 종료하므로 운영 사이트에서는 편집 버튼이 나타나지 않는다. ERP에서 문구를 관리하도록 구현한다면 이 로컬 편집 코드의 유지 여부를 정한다.
- 로컬 편집기에서 Enter는 `<br>`로 저장된다. 색상 강조가 있는 문구는 각 색상 부분을 별도로 클릭해 수정해야 스타일이 유지된다. 저장 시 파일 선택기 또는 HTML 다운로드를 사용한다.
- `C:\personal-erp`는 확인 결과 가계 결산용 별도 앱이다. 학원 ERP 프로젝트로 취급하거나 여기에 랜딩을 연결하지 않는다.
